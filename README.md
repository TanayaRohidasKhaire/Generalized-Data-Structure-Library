# Generalized-Data-Structure-Library
A multi-language collection of data structure implementations in **C, C++, and Java**.

## Overview

This repository contains implementations of fundamental data structures developed for learning, practice, and understanding data structure concepts across different programming languages.

## Languages

* C
* C++
* Java

## Data Structures

### Linked Lists

* Singly Linked List
* Doubly Linked List
* Circular Linked List

### Linear Data Structures

* Stack
* Queue

## Purpose

The purpose of this repository is to build, organize, and maintain implementations of data structures in multiple programming languages while strengthening programming and problem-solving skills.
