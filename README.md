\# DSLibrary



\## Generalized Data Structure Library



DSLibrary is a C++ project that provides implementations of commonly used

data structures. The project focuses on understanding how different data

structures work and how their operations can be implemented using C++.



The implementations use object-oriented programming, templates, pointers,

and dynamic memory allocation.



\## Features



\- Generic implementations using C++ templates

\- Supports different data types

\- Object-oriented design

\- Dynamic memory allocation

\- Insertion and deletion operations

\- Display and count operations

\- Menu-driven programs

\- Separate implementation for each data structure



\## Data Structures



The project includes the following data structures:



\- Singly Linear Linked List

\- Doubly Linear Linked List

\- Singly Circular Linked List

\- Doubly Circular Linked List

\- Stack

\- Queue



\## Operations



\### Linked Lists



The linked list implementations provide:



\- Insert at first position

\- Insert at last position

\- Insert at a given position

\- Delete from first position

\- Delete from last position

\- Delete from a given position

\- Display elements

\- Count elements



\### Stack



\- Push

\- Pop

\- Peep

\- Display

\- Count



\### Queue



\- Enqueue

\- Dequeue

\- Display

\- Count
